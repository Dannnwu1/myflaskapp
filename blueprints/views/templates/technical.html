Deploy Flask App on PythonAnywhere

Step 1: Sign Up for PythonAnywhere

  • Go to pythonanywhere.com
  • Create a free account (Beginner account available)
  • Verify your email

Step 2: Prepare Your Flask Application

Create a basic Flask app structure locally:

Project Structure:
myflaskapp/
├── app.py
├── requirements.txt
├── static/
└── templates/
app.py:
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    return render_template('index.html', title='Home')

@app.route('/about')
def about():
    return 'About Page'

if __name__ == '__main__':
    app.run(debug=True)
requirements.txt:
Flask==2.3.3
templates/index.html:
<!DOCTYPE html>
<html>
<head>
    <title>{{ title }}</title>
</head>
<body>
    <h1>Welcome to My Flask App!</h1>
    <p>Deployed on PythonAnywhere</p>
</body>
</html>

Step 3: Upload Your Code

Using Git (Recommended):
  1. Push your code to GitHub/GitLab
  2. In PythonAnywhere dashboard, open a Bash console
  3. Clone your repository:
    git clone https://github.com/yourusername/your-repo.git

Step 4: Set Up Virtual Environment

Bash Commands:
# Open a Bash console
# Navigate to your app directory:
cd ~/your-flask-app

# Create virtual environment:
python3.10 -m venv myenv

# Activate it:
source myenv/bin/activate

# Install requirements:
pip install -r requirements.txt

Step 5: Configure the Web App

  • Go to Web tab in dashboard
  • Click "Add a new web app"
  • Select "Manual configuration" (not "Flask")
  • Choose Python version
  • Click Next

Step 6: Configure WSGI File

Click on the WSGI configuration file link (will open in editor)
WSGI Configuration:
import sys
import os

# Add your app's directory to the Python path
path = '/home/yourusername/your-flask-app'
if path not in sys.path:
    sys.path.append(path)

# Import your Flask app
from app import app as application

Step 7: Configure Web App Settings

Web Tab Configuration:
  • Source code:
    Set to your app directory
  • Working directory:
    Set to your app directory
  • Virtualenv:
    /home/yourusername/your-flask-app/myenv
Static Files:
  • URL:
    /static/
  • Directory:
    /home/yourusername/your-flask-app/static/

Step 8: Deploy

Final Steps:
  1. Go back to Web tab
  2. Click the green Reload button
  3. Visit your app at: yourusername.pythonanywhere.com
